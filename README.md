# Visual Similarity Product Retrieval

## 📌 Project Overview
This project uses CNN and EfficientNetB0 to build a visual search system for fashion products.

---

## 🧠 Models Used
- Custom CNN (classification)
- EfficientNetB0 (feature extraction)
- FAISS (similarity search)

---

## 📦 Dataset
Fashion Product Images Dataset (Kaggle)  
https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-dataset

---

## 🚀 Features
- Image classification using CNN
- Feature extraction using EfficientNetB0
- Visual similarity retrieval using FAISS

---

## 📊 Results
- CNN Accuracy: ~89.94%
- EfficientNetB0: used for embeddings
- FAISS: fast similarity search system

---

## ▶️ How to Run
1. Open notebook  
2. Run all cells  
3. Ensure dataset path is correct  

---

## 📁 Models Included
- best_cnn_model.keras → Best CNN model  
- cnn_model_final.keras → Final CNN model  
- efficientnet_best.keras → Embedding model for retrieval
